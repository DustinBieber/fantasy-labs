# Fantasy Labs

| Path | What |
|---|---|
| `index.html` | Fantasy Labs dashboard (Sleeper league roster, trade, radar, news). |
| [`family-hub/`](family-hub/README.md) | Family Hub: chores and rewards, shared calendar, homework, money, health, location and door alerts. |
| [`ops-hub/`](ops-hub/README.md) | Ops Hub: orders, stock, freight and 3PL bills across Shopify, Extensiv, Lightspeed, RQ and Google Workspace. |
| [`sandbox/`](sandbox/SETUP.md) | The Mac mini side-hustle sandbox: a one-command installer that updates itself. **Start here:** [`sandbox/SETUP.md`](sandbox/SETUP.md) (step by step), then [`sandbox/README.md`](sandbox/README.md) (reference). |
| [`clipper/`](clipper/README.md) | First sandbox project: finds fantasy football creators without short-form, cuts subtitled clips from their episodes, and posts to their accounts after you approve. |

All of these can run on the same Mac mini. They use separate ports, folders and background jobs (see the bottom of
[`sandbox/SETUP.md`](sandbox/SETUP.md)).
